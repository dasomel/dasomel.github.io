# Image assets

- `brand/` — identity and icon-system reference assets
- `home/` — high-level OSS ecosystem visuals
- `story/` — engineering journey visuals
- `projects/<slug>/` — project architecture/evidence visuals

SVG is preferred for diagrams and infographics because it remains crisp and lightweight across desktop/mobile. Real screenshots should be added only when they provide evidence not already conveyed by the diagram, and should be optimized before committing.

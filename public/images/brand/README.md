# Brand & Visual Assets

- `icon.svg`: compact browser favicon / header-compatible connected-D mark.
- `icon-v2.svg`: full app/touch icon.
- `icon-maskable.svg`: PWA maskable icon with safe-zone padding.
- `og-workbench.svg`: 1200×630 social preview.

Project architecture and infographic visuals are rendered as accessible HTML/SVG-like UI components so they remain crisp, responsive, theme-aware, and readable on mobile. Real project screenshots can be added under `public/images/projects/<slug>/` when the source repository provides durable evidence assets; decorative stock imagery is intentionally avoided.

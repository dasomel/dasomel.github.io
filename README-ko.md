# dasomel.github.io

[English](README.md) | 한국어

Dasomel 커뮤니티의 공식 기술 블로그 및 엔지니어링 포털입니다.

## 기술 스택

- **프레임워크:** Next.js (App Router, Static Export)
- **스타일링:** Tailwind CSS
- **다국어(i18n):** 한국어(`ko`) 및 영어(`en`)
- **배포:** GitHub Pages

## 빠른 시작

```bash
# 의존성 설치
pnpm install

# 로컬 개발 서버 실행
pnpm dev

# 정적 빌드 및 산출물 생성
pnpm build
```

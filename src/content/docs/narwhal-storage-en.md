# Storage & Databases

Storage and stateful database engines accommodating diverse workload profiles.

## Storage Engines
- **NFS PVs**: Volume quota enforcement using XFS Project Quotas (`nfs-quota-agent`)
- **Object Storage**: SeaweedFS high-throughput distributed S3-compatible storage
- **CloudNativePG**: Production-grade HA PostgreSQL clusters with automated streaming replication

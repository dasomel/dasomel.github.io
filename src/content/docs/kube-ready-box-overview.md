# 박스 개요

Kube-Ready-Box는 로컬 쿠버네티스 개발 환경의 부트스트랩 시간을 0초로 단축하기 위한 베이스 박스입니다.

## 주요 목적
- XFS Project Quota 사전 활성화
- 최신 커널 파라미터 및 containerd v2 사전 구성
- ARM64(Apple Silicon) 및 AMD64 완벽 지원

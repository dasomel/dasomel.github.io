# KubeMetal 개요

KubeMetal은 Apple Silicon Mac에서 로컬 LLM을 가장 효율적으로 학습 및 서빙하기 위한 데스크톱 플랫폼입니다.

## 핵심 가치
- VM 가상화의 한계를 넘어 macOS 호스트 GPU/NPU 가속 직접 활용
- K3s 기반 선언적 MLOps 파이프라인 관리
- 직관적인 Tauri v2 데스크톱 GUI 환경

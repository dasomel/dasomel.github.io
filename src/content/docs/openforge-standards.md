# Standards

OpenForge 표준은 기대하는 outcome을 정의하고, 프로젝트가 구체적인 구현 방식을 선택하도록 합니다.

## Core

- Documentation / Repository
- GitHub / Development Tooling
- Change Management / Impact Analysis
- Upgrade / Compatibility

## Security

- Security baseline
- Supply Chain Security
- Package / Artifact Identity
- CI/CD Security / Resilience
- Secrets / Machine Identity
- Vulnerability Management
- Incident Response
- Release Security
- Security Exceptions

## Engineering

- Reproducible Build
- Developer Environment Security
- AI-assisted Engineering Security
- Container / Kubernetes / IaC Security
- Maintainer Governance
- OSS Compliance

정식 기준 문서는 [OpenForge repository](https://github.com/dasomel/openforge/tree/main/docs)에 있습니다.

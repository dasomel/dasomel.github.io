# Engineering Tooling Standard

Toolchains represent critical developer infrastructure shaping productivity and software maintainability.

## Principles

- **Standard Tools First**: Prioritize official and community-standard tooling within each ecosystem.
- **Pinned Versions**: Toolchain versions are pinned across local and CI environments to prevent drift.
- **Versioned Configs**: Linters and formatters are governed by root-level configuration files in source control.

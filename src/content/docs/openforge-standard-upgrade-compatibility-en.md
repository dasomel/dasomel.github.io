# Upgrade & Compatibility Engineering

Compatibility guarantees enable users and ecosystems to adopt software with confidence.

## Rules

- **Explicit Support Windows**: Supported runtime, OS, and Kubernetes version ranges documented in README.
- **Backward Compatibility**: Automated regression suites verify compatibility across minor and patch versions.
- **Deprecation Grace Period**: Deprecated interfaces require deprecation notices across at least one minor release cycle.

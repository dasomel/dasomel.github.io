# 플랫폼 개요

Beluga는 모던 데이터 스택을 로컬 쿠버네티스에서 완벽하게 구동할 수 있도록 설계된 IaC 솔루션입니다.

## 핵심 기능
- 실시간 CDC 수집 및 스트림 프로세싱
- Apache Iceberg 오픈 레이크하우스 아키텍처
- Trino 기반 고속 분산 SQL 분석 및 Superset 대시보드

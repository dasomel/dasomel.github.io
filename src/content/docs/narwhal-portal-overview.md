# 포털 개요

Narwhal Portal은 복잡한 IDP 인프라를 단일 UI로 추상화하여 개발자와 운영자에게 직관적인 워크벤치를 제공합니다.

## 주요 기능
- 클러스터 리소스 및 35개 GitOps 애플리케이션 상태 조회
- Keycloak 기반 통합 SSO 로그인 및 권한 관리
- 개발자 애플리케이션 프로비저닝 및 릴리스 파이프라인 연동

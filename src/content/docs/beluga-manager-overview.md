# 매니저 개요

Beluga Manager는 분절된 데이터 파이프라인 도구들을 단일 인터페이스로 융합합니다.

## 주요 관제 영역
- Kafka 토픽 및 파티션별 처리율
- Flink 스트리밍 애플리케이션 상태
- Iceberg 레이크하우스 테이블 메타데이터 및 스토리지 용량

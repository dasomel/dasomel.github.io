# Templates

Template은 구현의 시작점입니다. Version과 permission을 고정하고 placeholder를 교체한 뒤 대상 platform에서 검증합니다.

## Repository / CI

- PR / CODEOWNERS
- CI / Release Security
- SBOM
- Toolchain Verification
- Dependency Policy

## Platform

- Dockerfile
- Kubernetes Deployment / Service / Ingress / NetworkPolicy / PDB
- Kustomize
- Argo CD
- OIDC / SSO
- OpenTelemetry
- Backup / Restore
- Offline Bundle

## Design

- README 정보 구조
- Static Landing Page
- Architecture Diagram
- Project Status
- Design Tokens

원본은 [`templates/`](https://github.com/dasomel/openforge/tree/main/templates)에서 확인합니다.

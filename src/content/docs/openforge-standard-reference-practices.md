# 참고 관행 감사 표준

OpenForge의 표준은 이론적인 규범이 아니라 실제 프로덕션 OSS 프로젝트로부터 축적된 실증적 관행입니다.

## 참고 프로젝트 연계

- **Narwhal**: GitOps 35개 앱 운영 및 263건의 인시던트 교훈을 회귀 테스트로 체계화
- **KubeMetal**: 베어메탈 하드웨어 호환성 매트릭스 및 Makefile 태스크 통합
- **nfs-quota-agent**: Go `gofumpt` 린트 표준, systemd 유닛 템플릿, 통합 테스트
- **Beluga Manager**: 다국어 UI 번들(`ko-KR`, `en-US`) 및 컨테이너 보안 베이스라인

표준은 실제 프로젝트의 변경과 장애 회고를 통해 지속적으로 개정되고 개선됩니다.

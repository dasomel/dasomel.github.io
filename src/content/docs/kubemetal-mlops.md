# MLOps 가이드

KubeMetal에서 로컬 모델을 학습하고 서빙하는 파이프라인 가이드입니다.

## 주요 기능
- HuggingFace / Ollama 모델 원클릭 다운로드
- LoRA / QLoRA 파인튜닝 파이프라인 실행
- 4-bit / 8-bit MLX 양자화 변환 및 고속 서빙

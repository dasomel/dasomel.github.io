# Installation & Setup

Installation on storage hosts and Kubernetes cluster integration.

## Steps
1. Format partition with XFS and mount with `pquota`
2. Deploy `nfs-quota-agent.service` systemd unit
3. Deploy Helm chart to Kubernetes cluster

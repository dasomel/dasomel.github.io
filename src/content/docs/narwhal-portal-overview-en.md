# Portal Overview

Narwhal Portal abstracts complex IDP infrastructure into a unified developer workbench.

## Core Features
- Cluster resource and 35 GitOps application status inspection
- Keycloak-integrated SSO login and role-based access control
- Developer self-service provisioning and release pipeline tracking

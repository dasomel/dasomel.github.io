# Templates

Templates are implementation starting points. Always pin versions, replace placeholders, and validate against the target platform.

## Repository / CI

- PR and CODEOWNERS samples
- CI and release-security workflows
- SBOM workflow
- toolchain verification
- dependency policy

## Platform

- Dockerfile baseline
- Kubernetes Deployment, Service, Ingress, NetworkPolicy and PDB
- Kustomize base
- Argo CD Application
- OIDC/SSO contract
- OpenTelemetry baseline
- backup/restore runbook
- offline bundle manifest

## Design

- README information architecture
- static project landing page
- architecture diagrams
- project status
- design tokens

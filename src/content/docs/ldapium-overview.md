# ldapium 개요

ldapium은 안전하고 검증 가능한 엔터프라이즈 LDAP 디렉토리 서비스를 제공합니다.

## 핵심 원칙
- 공식 OpenLDAP 2.6 업스트림 소스로부터 직접 빌드
- 기본 관리자 패스워드 및 샘플 데이터 전무(Zero)
- 완벽한 라이선스 컴플라이언스(OpenLDAP Public License 2.8)

# Platform Overview

Narwhal is an open-source Internal Developer Platform (IDP) integrating 35 cloud-native components into a single reproducible system.

## Core Goals
1. **Reproducibility**: Identical behavior across Vagrant, Kakao Cloud, and air-gapped environments.
2. **Knowledge as Tests**: 263 incident lessons codified into 51 automated CI regression checks.
3. **Self-Contained Platform**: Complete IAM, GitOps, Observability, and Storage stacks running locally without SaaS dependencies.

# Development Guide

Local setup and contribution guidelines for Beluga Manager.

```bash
# Clone and install dependencies
git clone https://github.com/dasomel/beluga-manager.git
cd beluga-manager
pnpm install

# Start development server with mock backends
pnpm dev:mock
```

# 아키텍처 결정 기록 (ADR)

ADR(Architecture Decision Records)은 무엇을 구현했는지만이 아니라 **왜 그렇게 결정했는지, 어떤 대안과 트레이드오프가 있었는지**를 기록합니다.

## ADR 목록

### ADR-0001: 소스 자산과 공개 웹 문서의 분리
- **상태**: 승인됨 (Accepted)
- **결정**: OpenForge GitHub 저장소는 표준, 템플릿, 재사용 자산의 단일 진실 공급원(Source of Truth)으로 유지하고, `cne.io.kr` 웹 포털은 해당 자산을 설명하는 이중 언어 문서, 튜토리얼, 참조 해설 및 적용 증거를 제공합니다.
- **배경**: 코드 및 템플릿 구현과 사용자 대상 웹 문서를 단일 저장소에 섞지 않고 각자의 변경 주기에 맞게 독립적으로 발전시키기 위함입니다.

### ADR-0002: 이중 언어(영/한) 문서 1:1 대응 정책
- **상태**: 승인됨 (Accepted)
- **결정**: 모든 공식 문서는 영어(English)를 기본 표준으로 하고 한국어(Korean)를 1급 번역으로 동등하게 유지합니다.
- **배경**: 글로벌 오픈소스 생태계와의 협업을 보장하면서도 국내 개발자에게 정확한 기술 맥락을 전달하기 위함입니다.

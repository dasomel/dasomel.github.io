# App Setup & Installation

Step-by-step instructions for compiling and executing KubeMetal.

```bash
# 1. Clone and install dependencies
git clone https://github.com/dasomel/kubemetal.git
cd kubemetal
pnpm install

# 2. Launch Tauri in dev mode
pnpm tauri dev
```

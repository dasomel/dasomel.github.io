# OpenForge Documentation

OpenForge is the reusable engineering foundation for the Dasomel OSS portfolio.

It combines engineering standards, security and supply-chain governance, reusable implementation templates, deployment baselines, and design patterns.

## Documentation model

```text
OpenForge repository
    ↓
Standards + Templates
    ↓
Reference implementation in OSS projects
    ↓
cne.io.kr documentation
    ↓
Evidence / lessons / reusable knowledge
```

## Source of truth

Implementation assets live in the [OpenForge repository](https://github.com/dasomel/openforge). This site explains why and when to use them, the trade-offs, and how they are applied in real projects.

## 프로젝트 소개

**oh-my-cursor**는 Cursor IDE에서 여러 역할의 AI 에이전트가 협업하도록 만드는 multi-agent orchestration rules 프로젝트입니다.

단순한 프롬프트 모음보다 **어떤 작업을 어떤 agent에게 맡기고 어떻게 결과를 검증할 것인가**에 초점을 둡니다.

## 현재 방향

- Cursor IDE 기반 multi-agent workflow
- 역할별 agent orchestration
- 탐색·구현·검증 단계 분리
- 반복 가능한 AI-assisted development 패턴 실험

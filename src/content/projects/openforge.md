## 프로젝트 소개

**OpenForge**는 오픈소스 프로젝트를 만들고 발전시키고 유지하기 위한 공통 **Blueprint + Engineering Standards**입니다.

```text
Project Definition
      ↓
Repository Bootstrap
      ↓
Documentation / Architecture
      ↓
Development / CI / Security
      ↓
Release / Maintenance
      ↓
Lessons / Metrics
      ↓
OpenForge Improvement
```

특정 언어나 Framework를 강제하기보다 반복해서 적용할 수 있는 Engineering Foundation을 제공합니다.

## 주요 범위

- Repository 및 Documentation Standard
- GitHub Issue / PR / Actions Standard
- CI/CD 및 Supply Chain Security
- Release / Version Management
- 언어별 Development Tooling
- `gofumpt`, Code Intelligence, AI-assisted development
- English / Korean 문서 및 i18n 기준
- OSS License / Compliance
- Reference Implementation Metrics
- 재사용 가능한 Project Templates

## 참고 구현

Narwhal, Narwhal Portal, nfs-quota-agent, kube-ready-box, KubeMetal, ldapium, Beluga Manager 등 실제 개발 중인 OSS의 반복 가능한 관행을 OpenForge에 반영합니다.

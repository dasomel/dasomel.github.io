## Overview

**oh-my-cursor** is a set of multi-agent orchestration rules for Cursor IDE.

The project focuses less on prompt collections and more on **which agent should handle which work and how the result should be verified**.

## Current Direction

- Multi-agent workflow for Cursor IDE
- Role-based agent orchestration
- Separate exploration, implementation, and verification
- Experiments in repeatable AI-assisted development

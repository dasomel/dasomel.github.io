# CNE Palette Refresh

This refresh borrows visual principles rather than source code from permissively licensed Tailark blocks. Tailark's public blocks repository is MIT licensed. The CNE implementation is original and uses its own tokens and layout rules.

Design direction:

- warm neutral page canvas
- white primary surfaces
- strong graphite text
- restrained teal brand accent
- amber reserved for semantic signals and evidence states
- distinct code/documentation surfaces without heavy dark panels

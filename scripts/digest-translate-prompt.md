# Daily Digest 번역(translate) — Cowork 스케줄 태스크 프롬프트

> 이 파일은 **보강(`digest-enrich-prompt.md`)의 경량 대안**입니다.
> 요약을 쓰지 않고 **원문 제목과 발췌문을 한국어로 옮기기만** 합니다.
>
> 왜 필요한가: 수집 소스가 전부 영어라, 번역이 없으면 **한국어 포스트인데
> 제목도 본문도 영어**로 나갑니다. fallback 으로 발행된 날의 글이 그 상태입니다.
> 번역은 출력량이 보강의 1/10 수준이라 **보강 창(약 47분) 안에 훨씬 안정적으로**
> 끝나고, 요약과 달리 원문에 없는 사실이 끼어들 여지가 거의 없습니다.

**보강을 돌릴 시간·여력이 있으면 보강을 우선하세요.** 이 태스크는 보강이
어려운 날 원문 그대로 나가는 것을 막는 하한선입니다.

---

## 역할

당신은 기술 문서 번역자입니다. **요약하지 않고, 해설을 붙이지 않고,
빠뜨리지 않고** 옮깁니다.

## 작업 순서

### 1. 오늘 날짜의 데이터 파일 찾기
- 경로: `src/content/posts/.digest-data/<오늘 날짜 KST>.json`
- 날짜 형식: `YYYY-MM-DD` (KST 기준)
- 파일이 **없으면**: 오늘은 수집된 기사가 없는 것이므로 **아무 작업도 하지 말고 종료**하세요.
- 파일이 있으면 읽어서 `articles` 배열을 확인하세요.

### 2. 각 기사에 번역 필드 추가

`articles` 배열의 **모든 기사**에 아래 2개 필드를 추가합니다.
원본 필드(`source`, `category`, `title`, `link`, `date`, `excerpt`)는
**절대 수정하지 마세요.** 새 필드만 추가합니다.

| 필드 | 내용 |
|---|---|
| `titleKo` | `title` 을 한국어로 옮긴 것 |
| `excerptKo` | `excerpt` 를 한국어로 옮긴 것 |

**번역 규칙**

- **길이를 늘리지 마세요.** `excerpt` 는 RSS 발췌문이라 문장 중간에서 잘려 있는
  경우가 많습니다. 잘린 채로 옮기면 됩니다 — **뒤를 상상해서 채우지 마세요.**
- **없는 내용을 넣지 마세요.** 배경 설명, 해설, "왜 중요한가" 류의 문장은
  이 태스크의 범위가 아닙니다. 그건 보강이 할 일입니다.
- **기술 용어·고유명사는 그대로 둡니다.** Kubernetes, GitOps, Terraform,
  ArgoCD, Pod, CVE 번호, 제품명, 회사명, 버전 문자열 등은 번역하지 않습니다.
  한국어 문장 안에 원어 그대로 섞어 쓰는 것이 이 블로그의 표기 방식입니다.
- **제목은 제목답게.** 원문이 명사구면 명사구로, 의문문이면 의문문으로.
  기사 제목에 들어간 인용문(`"..."`)은 인용 부호를 유지한 채 옮깁니다.
- **수치·단위·날짜는 원문 그대로.** `5-10x`, `$35M`, `29 million` 같은 표기를
  임의로 환산하거나 반올림하지 마세요.
- 번역투를 피하고 자연스러운 한국어로 쓰되, **의미를 바꾸면서까지 매끄럽게
  만들지는 마세요.** 정확성이 우선입니다.
- 원문이 이미 한국어인 기사(예: LINE, 카카오 기술블로그)는 `titleKo`/`excerptKo`
  에 **원문을 그대로** 넣거나, 필드를 아예 생략하세요. 둘 다 안전합니다.

### 3. JSON 파일 덮어쓰기

번역 필드를 추가한 `articles` 로 같은 경로의 JSON 파일을 덮어씁니다.
구조(`date`, `generatedAt`, `count`, `articles`)는 유지하세요.

### 4. 마크다운 재생성 + 커밋 + 푸시

```bash
npm run digest:enrich-publish
```

한 명령으로 **검증 → 마크다운 재생성 → 커밋 → push** 까지 끝납니다.
번역만 한 경우 커밋 메시지는 `🌐 제목·발췌문 번역 - <날짜>` 로 붙습니다.

- 로그에 `done: N article(s), N translated` 가 찍히는지 확인하세요.
  `translated` 수가 기사 수와 같아야 정상입니다.
- 이 스크립트는 멱등합니다. 중간에 끊겨도 다시 실행하면 남은 것을 회수합니다.
- 상태가 이상하면 **거부합니다**(다른 브랜치 위, 필드 0건, 원격과 분기).
  강제 푸시는 하지 않습니다.

## 마감

**fallback 머지 시각(08:25 KST + 스케줄 지연)** 전에 push 되지 않으면
원문 그대로 발행됩니다.

## 참고

- 전체 파이프라인 설명: `docs/daily-digest.md`
- 보강(요약+인사이트) 버전: `scripts/digest-enrich-prompt.md`
- 생성기는 필드가 없으면 자동으로 원문 발췌로 폴백합니다. 따라서 일부 기사만
  번역해도 안전합니다(다만 가능하면 전부 채우세요).

## 스키마 빠른 참고

```jsonc
{
  "date": "YYYY-MM-DD",
  "generatedAt": "ISO-8601",
  "count": 3,
  "articles": [
    {
      // 수집 단계가 채운 원본 — 수정 금지
      "source": "The New Stack",
      "category": "devops",
      "title": "Terraform AzureRM provider 5.0 now generally available",
      "link": "https://...",
      "date": "ISO-8601",
      "excerpt": "HashiCorp today announced that version 5.0 of the",

      // 이 태스크가 추가하는 필드
      "titleKo": "Terraform AzureRM provider 5.0 정식 출시",
      "excerptKo": "HashiCorp 가 오늘 AzureRM provider 5.0 버전을"
    }
  ]
}
```

위 예시에서 `excerpt` 가 문장 중간(`version 5.0 of the`)에서 끊겨 있고
`excerptKo` 도 같은 지점(`5.0 버전을`)에서 끊겨 있다는 점에 주목하세요.
**이것이 올바른 번역입니다** — 뒤를 지어내지 않았습니다.

## Security Scope & Static Content

`dasomel.github.io` is a static Next.js documentation portal and blog hosted on GitHub Pages.
- No user authentication data, server databases, or private infrastructure credentials are hosted or processed.
- MDX/HTML rendering is sanitized to prevent cross-site scripting (XSS).

## Reporting a Vulnerability

Please report vulnerabilities responsibly via GitHub Private Vulnerability Reporting or by contacting maintainers directly.

Reference: [OpenForge Security Standard](https://github.com/dasomel/openforge/blob/main/docs/security.md)
